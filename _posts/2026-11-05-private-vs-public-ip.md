**둘 다 맞는 값이다.** 컴퓨터 설정 화면에 보이는 IP는 집·회사 안에서만 통하는 **사설 IP**이고, "내 IP 확인" 사이트가 보여 주는 값은 바깥 인터넷에서 보이는 **공인 IP**다. 공유기가 둘 사이를 이어 준다. (IP 주소: 네트워크에서 기기를 구분하는 번호.)

## 사설 IP는 따로 정해 둔 대역이다

[RFC 1918](https://www.rfc-editor.org/rfc/rfc1918.txt)은 내부망용으로 아래 세 범위를 정해 두었다. 원문에서 확인한 줄이다.

```
     10.0.0.0        -   10.255.255.255  (10/8 prefix)
     172.16.0.0      -   172.31.255.255  (172.16/12 prefix)
     192.168.0.0     -   192.168.255.255 (192.168/16 prefix)
```

이 범위의 주소는 인터넷에서 전달되지 않는다. 그래서 집집마다 같은 `192.168.0.x`를 써도 부딪히지 않는다.

Python `ipaddress`로 판별해 봤다 (Python 3.11.18).

```python
import ipaddress as i
for a in ['192.168.0.12','10.1.2.3','172.16.5.1','172.32.0.1','8.8.8.8']:
    x=i.ip_address(a); print(a, x.is_private, x.is_global)
```

```
192.168.0.12 True False
10.1.2.3 True False
172.16.5.1 True False
172.32.0.1 False True
8.8.8.8 False True
```

`172.32.0.1`은 `172`로 시작해도 사설이 아니다. 사설 범위는 `172.16`~`172.31`까지다.

## 두 값을 나란히 보기

이 글을 쓴 클라우드 샌드박스에서 직접 돌렸다. 앞은 기기가 가진 주소, 뒤는 바깥 서버가 본 주소다.

```
$ hostname -I
192.0.2.2
$ curl -s https://api.ipify.org
160.79.106.134
```

같은 기기인데 번호가 다르다. 기기는 자기 주소만 알고, 바깥 서버는 요청이 도착한 주소(중간 장비가 바꿔 단 주소)만 본다. 가정에서는 공유기가 이 변환(NAT)을 맡는다고 알려져 있다. 다만 이 샌드박스의 내부 구조는 확인하지 못했고, 사설 대역과 공인 주소가 갈린다는 현상만 확인한 것이다.

> 샌드박스의 `192.0.2.2`는 RFC 5737이 문서 예제용으로 지정한 `192.0.2.0/24`([RFC 5737](https://www.rfc-editor.org/rfc/rfc5737.txt))에 속한다. Python은 이 주소를 `is_private=True, is_global=False`로 판정했다. 공인 주소가 아니라는 점은 같다.

## 내 PC에서 확인하는 법

- 사설 IP: Windows는 명령 프롬프트에서 `ipconfig`, macOS·Linux는 `hostname -I` 또는 `ifconfig`.
- 공인 IP: 브라우저로 IP 확인 사이트에 접속하거나 `curl https://api.ipify.org`.
- 두 값이 다르면 정상이다. 공유기 관리 화면의 WAN 주소가 공인 IP와 같으면 공유기가 직접 공인 주소를 받은 경우다.
