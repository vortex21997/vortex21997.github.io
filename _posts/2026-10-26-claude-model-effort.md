> **2026-10 기준.** [모델 설정 문서](https://code.claude.com/docs/en/model-config)를 근거로 정리했다.
> 모델 라인업과 기본값은 자주 바뀌므로 `/model` 화면에서 확인하는 편이 정확하다.
{: .prompt-info }

`/model`을 눌렀을 때 **Enter와 `s`가 다르게 동작한다.**
이걸 모르면 "분명 Sonnet으로 바꿨는데 다음에 켜니 Opus네?" 하게 된다.

## 모델 별칭

전체 이름 대신 별칭을 쓴다.

| 별칭 | 쓰임 |
|---|---|
| `fable` | 가장 어렵고 오래 걸리는 작업 |
| `opus` | 복잡한 추론 |
| `sonnet` | **일상적인 코딩** |
| `haiku` | 빠르고 단순한 작업 |
| `opusplan` | 플랜 모드는 Opus, 실행은 Sonnet |
| `best` | 가능하면 `fable`, 아니면 `opus` |
| `default` | 계정 기본값으로 되돌림 |
| `sonnet[1m]`, `opus[1m]` | 같은 모델의 1M 토큰 컨텍스트 버전 |

별칭은 **권장 버전을 가리키고 시간이 지나면 바뀐다.**
버전을 고정하려면 `claude-opus-5-5` 같은 전체 이름을 쓴다.

> `opusplan`이 재밌는 선택지다. 계획은 비싼 모델로 세우고 실행은 싼 모델로 한다.
> 설계 판단이 중요한데 구현 자체는 단순할 때 맞는다.
{: .prompt-tip }

고르는 기준은 단순하다. **Sonnet이 대부분의 코딩을 잘 처리하고 Opus보다 싸다.**
Opus는 복잡한 구조 결정이나 여러 단계를 거치는 추론에 아껴 쓴다.

## effort — 얼마나 생각할지

effort는 **매 단계에서 모델이 얼마나 깊게 추론할지**를 조절한다.
낮으면 빠르고 싸고, 높으면 어려운 문제에서 더 깊게 판단한다.

값은 `low` `medium` `high` `xhigh` `max` 다섯 개다.
**모델마다 지원하는 범위가 다르고, 지원하지 않는 값을 고르면 그 이하 최고값으로 떨어진다.**

기본값도 모델마다 다르다. 대부분 `high`이고, Opus 5.5 / Sonnet 5.5 / Haiku 5.5는 `medium`이다.

> **Ultracode는 effort가 아니다.** Claude가 동적 워크플로를 조율하게 하는 별도 토글이고,
> 켜고 끈다고 effort가 바뀌지 않는다.
{: .prompt-warning }

## 여기가 핵심 — 저장되는 것과 아닌 것

### `/model`

| 동작 | 결과 |
|---|---|
| 피커에서 **Enter**, 또는 `/model sonnet` | 전환하고 **기본값으로 저장** (사용자 설정에 기록) |
| 피커에서 **`s`** | **이번 세션만** 전환. 기본값은 그대로 |
| `claude --model opus` | 그 세션만 |
| `ANTHROPIC_MODEL` 환경변수 | 그 세션만 |

"이번 작업만 Opus로 돌려보자" 할 때 Enter를 누르면 **그게 새 기본값이 된다.**
그럴 의도가 아니었다면 `s`를 눌러야 한다.

### `/effort`

| 동작 | 결과 |
|---|---|
| 슬라이더에서 **Enter**, 또는 `/effort high` | 그 모델에 대해 **저장** |
| 슬라이더에서 **`s`** | 이번 세션만 |
| `/effort auto` | 저장된 값을 지우고 모델 기본값으로 |
| `max` | **환경변수로 주지 않는 한 항상 이번 세션만** |

effort는 **모델별로 따로 저장된다.** Opus는 `high`, Haiku는 `low` 식으로 각각 기억한다.

## 우선순위

같은 걸 여러 군데서 정하면 위에서부터 이긴다.

**모델**

```
1. /model <이름>              세션 중
2. claude --model <이름>      시작할 때
3. ANTHROPIC_MODEL            환경변수
4. 설정 파일의 model 키
5. ANTHROPIC_DEFAULT_MODEL    새 세션의 기본값
```

**effort**

```
1. CLAUDE_CODE_EFFORT_LEVEL / --effort / /effort
2. 저장된 설정 (modelSettings 또는 effortLevel)
3. 모델의 기본값
```

## 비용 쪽에서 알아둘 것

- **서브에이전트는 세션 모델을 물려받는다.** 메인을 Opus로 올리면 서브에이전트도 Opus로 돈다.
  단순한 보조 작업이면 서브에이전트 정의에 `model: haiku`를 박아두는 게 낫다.
- **확장 사고(thinking) 토큰은 출력 토큰으로 과금된다.** 기본 예산이 요청당 수만 토큰까지 갈 수 있다.
  단순 작업에서는 effort를 낮추는 게 바로 돈이 된다.
- **Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable은 thinking을 끌 수 없다.** 항상 확장 사고를 쓴다.
  이 모델들에서는 effort 조절이 유일한 레버다.

## 세션 중에 바꿀 때

모델을 바꾸면 **프롬프트 캐시가 모델마다 따로**라서,
전환 후 첫 요청은 대화 전체를 캐시 없이 다시 읽는다.

effort를 바꿔도 비슷한 경고가 뜰 수 있다. 새 값은 다음 요청부터 적용된다.

즉 **자주 왔다 갔다 하는 것 자체가 비용**이다. 작업 단위로 정하고 그 동안 유지하는 편이 낫다.

## 정리

| 하고 싶은 것 | 방법 |
|---|---|
| 이번만 다른 모델 | `/model` 피커에서 **`s`** |
| 기본값 바꾸기 | `/model` 피커에서 **Enter** |
| 이번만 깊게 생각시키기 | `/effort` 슬라이더에서 **`s`** |
| effort 저장값 지우기 | `/effort auto` |
| 지금 뭐로 돌고 있나 | `/status` |

기억할 건 하나다. **`s`는 이번만, Enter는 저장.**
